# 🔐 Password Generator

## Description

A simple and responsive password generator built with HTML, CSS, and JavaScript.
Users can generate random passwords with customizable length and character types.

## Features

- Generate random passwords
- Customizable password length
- Uppercase letters
- Lowercase letters
- Numbers
- Symbols
- Copy password
- Responsive design
- Touch-friendly interactions

## Technologies

- HTML5
- CSS3
- JavaScript
